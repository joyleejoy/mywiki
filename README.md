# mywiki

로컬에서 작동하는 위키페이지 - 메모장.

마크다운 파일로 글을 남기는 개인용 위키. 파이썬 표준 라이브러리와 `markdown` 패키지만 쓰고,
`127.0.0.1` 에만 붙는 로컬 서버라 바깥에서는 접근할 수 없다.

## 실행

```
pip install -r requirements.txt
python wiki.py [포트]        # 기본 포트 8800
```

윈도우에서는 `위키 실행.bat` 을 더블클릭하면 서버가 뜨면서 브라우저가 열린다.
주소는 <http://localhost:8800/>. 파이썬 없이 쓰려면 `exe 만들기.bat` 으로 `위키.exe` 를 만든다.
실행하면 트레이 아이콘이 뜨고, 거기서 열기·종료를 할 수 있다.

## 기능

- **글쓰기** — 폴더·제목·본문을 한 화면에서 쓰고, 오른쪽 위 **저장**(`Ctrl+S`) 또는 **게시** 로
  저장한다. Enter 를 여러 번 누르면 누른 만큼 줄이 띄워진 채로 저장된다.
- **두 가지 편집 모드** — **마크다운**(원본을 그대로 고치기)과 **서식 편집**(꾸며진 화면에서
  바로 고치기). 모드를 오갈 때마다 서버가 마크다운 ↔ HTML 로 옮겨 적으며, 저장되는 파일은
  언제나 마크다운이다.
- **마크다운** — 표, 코드블록, 목록 등 기본 문법. 편집창 위 서식 버튼으로 굵게·제목·목록·숫자
  목록·인용을 넣는다. 목록과 인용은 Enter 로 이어지고 빈 항목에서 Enter 를 누르면 끝난다.
  문단 바로 아래에 빈 줄 없이 붙여 쓴 목록·표도 알아서 인식한다.
- **표** — **표** 버튼의 격자 대화상자로 만든다. 표 안에서는 화살표로 칸 사이를 오가고(위아래는
  바로, 좌우는 글자 끝에서), 맨 윗줄·맨 아랫줄에서 더 누르면 표 밖으로 나온다.
- **글 연결** — **글 연결** 버튼 하나로 처리한다. 목록에서 이미 있는 글을 골라 링크를 걸거나,
  `＋ 새 글 만들기` 로 새 글을 만들어 연결한다. 글자를 골라 두고 누르면 그 글자에 링크가 걸리고,
  링크가 걸린 글자는 나중에 그대로 고칠 수 있다(가리키는 글은 그대로 남는다).
  직접 쓸 때는 `[[문서 이름]]`, `[[폴더/문서 이름]]`, `[[문서|보일 글자]]`. 아직 없는 문서는
  빨간 링크로 보이고 누르면 새로 만들어진다. 같은 이름의 문서가 하나뿐이면 폴더를 생략해도 찾아간다.
- **메모** — 글을 읽다가 글자를 고르면 나오는 **📝 메모 붙이기** 로 그 자리에 메모를 남긴다.
  메모가 붙은 자리는 노랗게 표시되고, 눌러서 보고 고칠 수 있다.
- **댓글** — 글 아래에 댓글을 남긴다. 마크다운을 그대로 쓸 수 있고(`Ctrl+Enter` 로 등록),
  올린 뒤에도 `✎` 로 고치고 `✕` 로 지운다. 글을 옮기거나 이름을 바꾸면 댓글도 따라간다.
- **내 PC 파일** — 내 컴퓨터의 파일이나 코드 위치(`파일:줄번호`)로 가는 링크를 넣는다.
- **첨부** — 편집창에 파일을 끌어다 놓거나 스크린샷을 붙여넣으면 `files/` 에 저장되고 본문에
  링크가 들어간다.
- **그림** — **그림** 버튼으로 자유선·직선·사각형·타원·화살표를 그린다. SVG 한 장으로
  `files/` 에 저장되며, 서식 편집 모드에서 그림을 두 번 누르면 다시 열어 고칠 수 있다.
- **폴더** — `개발/서버` 처럼 여러 단계. 글이 없어도 폴더만 미리 만들 수 있고, 이름을 바꾸면
  안의 문서와 하위 폴더가 통째로 따라 옮겨지면서 다른 글에 걸린 링크도 함께 고쳐진다.
- **좌측 목록** — 폴더와 문서를 한눈에 보고, 끌어다 놓아 옮기거나 순서를 바꾼다. `☰` 로 접을 수 있다.
- **검색** — 제목과 본문을 함께 찾고, 찾은 말을 강조해 발췌를 보여 준다.

## 여러 기기에서 쓰기

글과 첨부를 두는 **데이터 폴더**를 고를 수 있다. 기본은 프로그램 옆이고, ⚙ 설정에서
OneDrive·Dropbox 같은 동기화 폴더를 지정하면 다른 기기에서도 같은 내용을 보고 고칠 수 있다.

- 지정한 폴더에 **이미 위키 내용이 있으면 그것을 그대로** 쓴다. 두 번째 기기에서는 같은
  동기화 폴더를 지정하기만 하면 된다.
- 내용이 없으면 **지금 내용을 그 폴더로 옮긴다**.
- 입력칸을 비우고 저장하면 프로그램 옆으로 되돌아온다.
- 선택한 위치는 `location.json` 에 남으며, 기기마다 다르므로 저장소에는 올리지 않는다.
  실행할 때 `python wiki.py --data "D:\\경로"` 로 직접 지정할 수도 있다.
- 서버는 여전히 `127.0.0.1` 에만 붙는다. 동기화 폴더를 볼 수 있는 사람만 내용을 볼 수 있으므로,
  개인 계정의 동기화 폴더를 쓰면 나만 보게 된다.
- 두 기기에서 같은 글을 동시에 고치면 동기화 프로그램이 충돌 사본을 만들 수 있으니, 한 번에
  한 곳에서 쓰는 편이 좋다.

## 저장 구조

```
pages/               문서. 폴더 구조 그대로 .md 파일로 저장된다
  개발/서버/메모.md
  .order             그 폴더의 표시 순서 (한 줄에 하나, 폴더는 끝에 /)
files/               첨부한 이미지·파일
config.json          위키 이름 등 설정
comments.json        글마다 달린 댓글
```

내용은 전부 평범한 파일이라 탐색기나 편집기로 직접 손봐도 그대로 반영된다.
`pages/`, `files/`, `config.json`, `comments.json` 은 개인 데이터라 저장소에 올리지 않는다.
